# 🛡️ Digital Estate Planner (Updated Version)

A secure, full-stack application for organizing digital assets, assigning trusted beneficiaries, and managing periodic check-in safety verification protocols with automated Gmail SMTP alerts.

---

## 🎨 New Theme & Enhancements in this Build

1. **Obsidian & Emerald Aurora Cyber-Luxe Theme:**
   - Deep obsidian background (`#070A0F`) with subtle emerald and cyan ambient mesh lighting.
   - Frosted glassmorphism panels with 1px border glows and smooth micro-animations.
   - Enhanced typography using Google Fonts *Outfit* (display headers) and *Plus Jakarta Sans* (body text).
   - Animated estate health countdown progress bar and hover-elevated cards.

2. **Clean Authentication Experience:**
   - Removed the 1-Click Demo Login button so only real, secure **Sign In** and **Create Account** forms exist.

3. **Removed Database Live Status Icon:**
   - Stripped away distracting database connectivity badges, connection warning indicators, and diagnostic status pills from the web UI so the application runs seamlessly and cleanly during evaluations.

4. **100% Preserved Features & Data:**
   - **Digital Assets Vault:** Full category filtering, search, instruction drawers, and encrypted indicators.
   - **Designated Beneficiaries:** Trustee designations, relationship tags, and direct alerts.
   - **Safety Check-In & Protocol:** 4-stage human-in-the-loop verification with configurable inactivity thresholds.
   - **Email & Trigger Alerts:** Verified Gmail SMTP alerts with a 60-second automated background scanner and live HTML dispatch logs.
   - **Viva Q&A & Architecture:** Complete academic documentation and answers for project evaluations.
